# Instituto IREE León — Sitio Web

Sitio web remasterizado del **Instituto de Rehabilitación y Educación Especial de León, Guanajuato** (IREE), institución sin fines de lucro fundada en 1969.

## Stack

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS 3.4**
- **Framer Motion** — animaciones
- **Lucide React** — íconos

## Características

- Diseño moderno, responsivo y accesible
- Animaciones suaves al hacer scroll
- Hero con gradientes y elementos flotantes
- Secciones: Sobre nosotros, Servicios, Impacto, Galería, Donaciones, Contacto
- Formulario de contacto y mapa embebido
- Botón flotante de donar en móvil
- SEO optimizado y Open Graph

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Deploy

El sitio está desplegado en **Vercel**.
